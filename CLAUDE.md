## Commands

```bash
pnpm dev              # start dev server (http://localhost:5173)
pnpm build            # type-check + production build
pnpm test             # run all unit tests
pnpm test:unit        # run unit tests with Vitest (jsdom)
pnpm test:e2e         # run Playwright e2e tests against built app
pnpm lint             # ESLint
pnpm typecheck        # vue-tsc type check only

# Run a single test file
pnpm test:unit --run src/tools/<name>/<name>.service.test.ts

# Scaffold a new tool
pnpm run script:create:tool my-tool-name
```

## Architecture

**IT Tools** is a Vue 3 SPA — a collection of single-page developer utilities. Each tool is fully self-contained in its own folder and registered centrally.

### Adding a tool: the three-file pattern

Every tool lives in `src/tools/<tool-name>/` and contains:

| File | Purpose |
|---|---|
| `index.ts` | Tool metadata — call `defineTool({name, path, description, keywords, component, icon, createdAt, redirectFrom?})` |
| `<tool-name>.vue` | UI only — uses `<script setup>` + Composition API |
| `<tool-name>.service.ts` | Pure logic with no Vue imports — what gets unit tested |
| `<tool-name>.service.test.ts` | Vitest unit tests for the service |

### Registration flow

1. `src/tools/<tool-name>/index.ts` — `defineTool(...)` exports `tool`
2. `src/tools/index.ts` — import and place `tool` in the correct `toolsByCategory` category array
3. `src/router.ts` — auto-generates routes from the tools list; no manual route editing needed
4. `components.d.ts` — auto-generated by Vite; never edit manually

`defineTool` auto-sets `isNew: true` when `createdAt` is within the last 2 weeks (`src/tools/tool.ts`).

### Key composables

- `useValidation` (`src/composable/validation.ts`) — reactive validation with `{ source, rules: [{ validator, message }] }`; returns `{ isValid, status, attrs }` — pass `attrs` or `validation` prop to `c-input-text`
- `useQueryParam` (`src/composable/queryParams.ts`) — syncs a ref to a URL query param; supports string/number/boolean/object types

### UI components

- `c-input-text`, `c-card`, `c-button`, `c-select`, `c-tooltip` — custom wrappers (auto-imported, defined in `src/ui/`)
- `n-*` components — Naive UI (also auto-imported)
- UnoCSS utility classes are used inline on elements (e.g. `flex`, `gap-4`, `mb-5`)

### State

- **Pinia** (`src/tools/tools.store.ts`) — manages the tools list, favorites (persisted to `localStorage` via `useStorage`), and new-tool detection
- **vue-i18n** — tool names/descriptions fall back to the `defineTool` values when no i18n key exists; add keys under `tools.<tool-path-without-slash>.title/description` in `locales/en.yml` (and other locale files) to translate

### Timezone / date handling

Native `Intl.DateTimeFormat` is used for timezone conversion — no extra dependency. `date-fns` is available for other date formatting.
